Project:- Retail Sales Performance Analysis & Business Intelligence Dashboard

Problem Statement:-
Retail transaction data contains valuable information about sales, products, and customers, but raw data makes it difficult for businesses to identify performance trends and make informed decisions. This project addresses the problem by transforming raw retail transaction data into an interactive Business Intelligence solution.


Solution:-
Developed an end-to-end retail analytics pipeline using Python, MySQL, SQL, and Power BI. The data was cleaned and explored using Python, stored and analyzed using MySQL and SQL, and transformed into an interactive Power BI dashboard containing KPIs, sales trends, product performance, and customer insights.


Why I Built It:-
I built this project to demonstrate the complete Data Analytics lifecycle—from raw data preparation and SQL analysis to BI dashboard development and business insight generation.


What I Found:-
The analysis identifies key revenue drivers, high-performing product categories, customer purchasing patterns, sales trends, and average transaction performance. These insights can support inventory planning, marketing strategies, and sales decision-making.


Tech Stack:-
Python | Pandas | MySQL | SQL | Power BI | DAX | Jupyter Notebook | Git/GitHub | NumPy | Matplotlib
